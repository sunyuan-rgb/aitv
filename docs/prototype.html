题目04 原型：短剧内容上架、付费观看与下架处理

流转主线：编辑提交 → 审核通过 → 运营上架 → 用户试看/购买/观看 → 运营停售/暂停 → 客服退款 → 恢复与核查

登录页 /login

预置账号下拉：editor / reviewer / ops / support / u1(500币) / u2(300币) / u3(100币)

状态：用户名或密码错误 → 展示失败原因

编辑工作台 /editor

集序状态操作
第3集已上架修改资料 → 生成待审修订（每集最多1份）
第5集审核退回（原因：资料有误）修改重提 → 待审核

异常：待审修订已存在 → 「该集已存在待审修订」；已上架内容不可改免费/付费属性

审核工作台 /reviewer

对象提交人操作
第3集（修订）editor通过 / 退回（原因必填）

异常：自审拦截 → 「不能审核自己提交的内容」；修订通过后需运营「发布修订」才替换线上版本

运营内容管理 /ops

集序状态购买人数待处理退款操作
第3集暂停观看（原因展示）21恢复
第5集停止销售（已购可看）30恢复
第6集已上架10停售 / 暂停（原因必填）

附：已审核通过待发布修订列表 + 操作留痕（动作/操作人/原因/时间）

用户剧集目录 /catalog

剧集属性状态操作
第1集免费在售▶ 免费试看
第3集100 币在售购买（含请求编号防重复扣币）/ 观看入口
第5集100 币停止销售仅已购用户可观看入口

购买异常：余额不足 / 停止销售 / 暂停观看 / 已拥有权益（幂等提示）

观看页 /play/:id 与退款

▶ 正在播放（演示地址）：/static/demo/ep3.mp4
无法观看：该集已暂停观看（运营原因展示）；你的权益已随退款撤销，内容恢复后可重新购买

暂停期间已购用户：填写原因 → 申请退款 → 客服处理

客服工作台 /support

退款单用户剧集金额操作
#1u1第3集100 币批准（退币+撤权益，只退一次）/ 驳回（原因必填）

权益核查：输入用户名+剧集ID → 展示「为何能看/不能看」+ 余额 + 购买次数 + 退款单状态

异常：重复处理 → 「该退款申请已处理，不能重复处理」
