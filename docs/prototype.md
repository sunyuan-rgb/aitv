# 原型设计 — 题目 04（最小业务页面）

页面采用服务端渲染 HTML（无复杂视觉设计），满足"发起业务、查询结果、展示失败原因"。

## 页面清单与状态说明

| 页面 | 路径 | 角色 | 覆盖操作与状态 |
| --- | --- | --- | --- |
| 登录页 | `/login` | 全部 | 预置账号登录（下拉选择+密码固定），失败原因展示 |
| 内容工作台 | `/editor` | 编辑 | 列表：各集状态；表单：编辑资料、提交审核；退回原因展示；修改重提 |
| 审核工作台 | `/reviewer` | 审核 | 待审列表；通过 / 退回（原因必填）；自审拦截提示 |
| 运营内容管理 | `/ops` | 运营 | 每集状态（已上架/暂停/停售）；上架 / 停售 / 暂停 / 恢复（原因必填）；购买人数、待处理退款数 |
| 剧集目录 | `/catalog` | 用户 | 已上架剧集卡片；免费集「试看」，付费集显示价格与「购买」；已购标记；停售/暂停状态对用户可见 |
| 观看页 | `/play/<ep>` | 用户 | 免费集 / 持权益 → 演示播放地址；无权益 → 失败原因；暂停集 → 「暂停观看+原因」 |
| 我的消费记录 | `/me` | 用户 | 购买记录（扣币）、退款记录、当前权益；失败请求原因 |
| 退款申请 | 在观看失败页 / `/me` 内发起 | 用户 | 暂停集已购用户发起；免费集/未购被拒原因 |
| 客服工作台 | `/support` | 客服 | 待处理退款列表；批准（退币+撤权益）/ 驳回（原因）；用户权益核查查询（输入用户名查"为何能看/不能看"） |

## 主要异常状态展示

- 购买失败：余额不足 / 停止销售 / 暂停观看 / 已拥有权益（幂等提示）
- 播放失败：未购买 / 权益已退款 / 暂停观看（附运营原因）
- 审核失败：自审拦截 / 已有待审修订 / 退回原因
- 退款失败：非暂停期 / 未购买 / 免费集 / 已申请过（只退一次）
- 越权：非本人消费记录、非本角色操作 → 403 提示

## 原型文件

`docs/prototype.html` —— 单页可点击原型（静态 HTML，展示各角色页面布局与状态流转），实际实现以 `web/templates` 为准。
